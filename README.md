# Coder With BCA — Portfolio

A responsive, single-page developer portfolio for **Akash Maurya**.

## Files
- `index.html` — complete portfolio (HTML, CSS, and JavaScript in one file).

## Publish with GitHub Pages
1. Create a new public repository named `portfolio` (or another name you prefer).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your site URL will usually be:
   `https://coder-with-bca.github.io/Portfolio/`

If you name the repository exactly `coder-with-bca.github.io`, the site URL will instead be:
`https://coder-with-bca.github.io/`
